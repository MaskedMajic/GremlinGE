# GremlinGE

GremlinGE is a local flip-scanner and limit-tracker for OSRS Grand Exchange flipping.

## v0 goal
Build the core "flip brain" before any RuneLite plugin work:
- fetch market data
- rank high-volume flip candidates
- show top opportunities
- later track 4-hour buy limits and personal offer activity

## Current phase
v0.1 market scanner scaffold.
